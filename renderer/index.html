Parked:

VibeCMD

  • Move a pane: drag its title bar onto another pane. Drop on an edge to put it there, in the middle to swap.
  • Resize: drag the gaps between panes. Double-click a gap to make its two neighbours equal; Even out in the toolbar does it for all.
  • Rename: double-click a title, or right-click a pane's title bar to rename or recolour it.
  • Automatic names: panes name themselves after what they're doing: a Claude pane after its chat's topic, a shell pane after the command running in it (or its folder while idle). Renaming a pane yourself stops this for that pane.
  • Park (▁) hides a pane but keeps it running. Drag it back from the bottom tray, or click it there.
  • Maximize (□) fills the tab with one pane; press it again to restore.
  • Pop out: drag a pane's title bar outside VibeCMD to turn it into a normal console window (Claude resumes its chat). Drag that window back in to dock it again.
  • Ctrl+scroll over a terminal changes its text size.
  • A pulsing dot means something is running in that pane (Claude working, or a command that hasn't finished). Only then does closing the pane, its tab or VibeCMD ask first.
  • New session: right-click a pane. It previews where the new pane goes (nearest edge); pick Claude / Duplicate / CMD / PowerShell, or click elsewhere to cancel.
  • Hold right-click for a wheel: move towards a slot and release (up Claude, right CMD, down PowerShell, left Duplicate, corners Park / Maximize / Close / Pop out). Edit the slots in Layout settings.
  • +C / >_ on a pane: new Claude / CMD right next to it, in the same folder.
  • New Claude asks which folder to open in, starting at the last one you picked. 📁 in the toolbar is that last folder.
  • Drag a folder or file from your file manager onto a pane edge to open CMD / Claude / PowerShell in that folder. A file can also be opened in an editor pane there.
  • Open file… in the right-click menu: pick a file, starting in that pane's folder, and it opens in an editor pane where the preview showed. It can go on a wheel slot too.
  • Editor panes are VibeCMD's own text editor (the one VS Code is built on): syntax colours, Find / Replace (Ctrl+F / Ctrl+H), multiple cursors (Alt+click), Go to line (Ctrl+G), word wrap (Alt+Z). Notepad++ keys work too: Ctrl+D duplicate line, Ctrl+L delete line, Ctrl+Shift+Up/Down move line, Ctrl+J join lines, Ctrl+U / Ctrl+Shift+U lower / UPPER case, Ctrl+Q comment. Right-click has line endings, encoding, sort lines and trim spaces. Each pane has its open files along its top: Ctrl+O open, Ctrl+N new, Ctrl+S save, Ctrl+Shift+S save as, Ctrl+W close the file. A file changed outside (by Claude, say) reloads by itself and the changed lines light up; if you have unsaved changes it asks first.
  • Browser panes: right-click, Browser. Type an address or a search in its bar (Ctrl+L). Alt+Left/Right back / forward, F5 reload, ⇱ opens the page in your normal browser. Links that open a new tab open a new browser pane. Sign-ins are kept between launches.
  • Send to Claude: select text in any terminal, right-click, "Send to …" a Claude pane (this tab's first). It's pasted into Claude's prompt without sending, so you can add your question and press Enter.
  • Linked editor: right-click a Claude pane's title bar, "Show Claude's edits in …" an editor pane in this tab (or a new one, opened at Claude's first edit). Every file Claude edits or writes then opens there, with the changed lines lit up.
  • Ctrl+Shift+P jumps to any pane or tab by typing part of its name, tab or folder.
  • Everything is saved automatically. Next launch reopens every tab and pane in the same layout and folders, and each Claude pane continues its own chat.
  • Tabs (top): + opens a new tab, double-click to rename, drag to reorder, middle-click to close. Drop a pane on a tab to move it there.
  • Layouts: right-click a tab, "Save layout…". Right-click the bar above the panes to open a saved layout or go to Layout settings (rename, delete, or click one to edit its panes).
  • A saved layout is a whole working set: each pane's kind, folder, name and colour, a shell pane's start command, an editor pane's file, and which editor shows a Claude pane's edits. Claude panes start fresh chats (or, set in the layout editor, continue the folder's last chat). Docked CMD windows aren't part of layouts.
  • Open in… (Layout settings) opens a layout for another project folder: every pane's folder and editor file moves along with it.
  • Start command: right-click a CMD / PowerShell pane's title bar to give it a command (say npm run dev) that's typed in whenever it starts, also after restarting VibeCMD. Layout editor panes have one too.

Windows: drag and drop. Linux: right-click, Dock a window…, then pick the window. This needs X11 (or an XWayland app) and the xdotool and xprop programs. On Linux the app's window is laid over the pane without a title bar and follows VibeCMD around; only apps with an X11 window can be docked, and docked CMD-style consoles are Windows only.

  • Drag an open CMD window onto VibeCMD (by its title bar) to dock it into a pane, or drop it on a tab (or + for a new tab) to dock it there. Whatever runs in it, even a Claude chat, keeps running untouched; the window itself is hidden (and leaves the taskbar) while the pane shows it.
  • Drag an app window onto VibeCMD the same way: Notepad, Notepad++, Kate, or most other programs. The app itself moves into the pane, and everything in it (menus, shortcuts, dialogs) works as usual.
  • ⇱, or dragging the pane's title bar out of VibeCMD, gives a docked window back as a normal window.
  • ✕ closes a docked CMD window for good. For a docked app it's the same as the app's own close button: it asks to save unsaved work, and Cancel keeps it open.
  • Quitting VibeCMD closes docked apps one by one, showing each, so you can save. Cancel in any of them and VibeCMD stays open, just as it was.
  • Docked apps reopen in their panes next launch, started with the same file. Docked CMD windows don't.
  • Unsaved changes in a docked app or an editor pane show as a hollow dot and "unsaved" in its title bar, and ● on its tab.
  • While a docked app has the keyboard, VibeCMD's own shortcuts go to the app. Click a terminal pane (or a title bar) to get them back.
  • Ctrl+Shift+N new Claude
  • Ctrl+Shift+D new CMD
  • Ctrl+Shift+T new tab
  • Ctrl+Shift+P go to any pane or tab by name (plain Ctrl+P is left to Claude and shells: previous history entry)
  • Ctrl+Tab / Ctrl+Shift+Tab (or Ctrl+PgUp/PgDn) switch tabs, from anywhere, even inside Claude
  • Tab / Shift+Tab switch tabs when no pane has focus (e.g. an empty tab); inside a pane they go to the shell / Claude as usual
  • Ctrl+Shift+W close focused pane
  • Ctrl+Shift+Enter maximize / restore focused pane
  • Alt+Shift+Arrows move focus between panes
  • Alt+K / Alt+Shift+K next / previous pane in this tab (not Ctrl+K: Claude Code uses it to delete to end of line)
  • Shift+Arrows / Ctrl+Shift+Arrows / Shift+Home/End / Ctrl+A select in Claude's prompt (type, paste or Backspace to replace it, Ctrl+C / Ctrl+X to copy / cut); after a click in the output, they select there instead
  • Ctrl+C copies when text is selected, otherwise interrupts
  • Ctrl+V paste (Copy / Paste are also in the right-click menu)
  • Esc closes this window
